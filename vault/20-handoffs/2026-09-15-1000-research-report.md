## Recommendations

1. **Q1 (Player Identity): Ignore automated jersey OCR.** The A100 compute cost (1.1 FPS) is completely unviable for this pipeline. The current blocker cannot be solved cheaply with computer vision. **Recommendation:** Rely on manual hand-mapping for the 1-2 critical players per video, or stick to anonymous tactical shapes.
2. **Q2 (Animation): Adopt Step-Based Interpolation.** Do not try to reconstruct continuous player tracking. **Recommendation:** Build a 2D animation tool that takes sparse data (e.g., nominal formation as Step 1, average positions as Step 2) and tween-animates the dots between them to create "spectacle" without tracking data.
3. **Q3 (Agent Architecture): Ignore the Reddit advice to split agents.** The overhead (token cost, latency) outweighs the benefit. **Recommendation:** Maintain the single script generator prompt/agent. 
4. **Q4 (Anti-Hallucination): Implement Typed Schemas.** **Recommendation:** Update `script_gen.py` to enforce a Pydantic schema for match facts (e.g., extracting scorers). Implement a "No-Compute Discipline" where Python explicitly validates the LLM's output against `match_data.json` team sheets *before* TTS generation, replacing the current human-in-the-loop `.script_verified` gate with an automated schema validation gate.
